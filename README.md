# Customer_Shopping_Behavior_Analysis
An end-to-end data analytics project using Python, SQL, and Power BI to analyze customer shopping behavior 


1. Project Overview

Customer Shopping Behavior Analysis is a real-world data analytics project focused on analyzing customer purchasing patterns, shopping preferences, sales performance, and customer behavior.

The project uses Python for data cleaning and Exploratory Data Analysis (EDA), SQL for data querying and analysis, and Power BI for creating an interactive dashboard.

2. Dataset Description

The dataset contains customer shopping information that helps analyze purchasing behavior and identify business trends.

Dataset includes:

- Customer information
- Product categories
- Purchase details
- Payment methods
- Shopping preferences
- Customer ratings
- Sales information

3. Tools & Technologies

- Python: Data cleaning, preprocessing, and Exploratory Data Analysis (EDA).
- Pandas: Data manipulation and analysis.
- SQL Server: Data querying and analysis.
- Power BI: Interactive dashboard creation.
- Excel: Dataset handling and initial analysis.

4. Project Steps

Step 1: Data Loading

- Imported the dataset into Python.

Step 4: SQL Analysis
